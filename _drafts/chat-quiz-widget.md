Chat Quiz runs a round of multiple-choice questions on screen. Viewers answer in chat, the widget keeps score, and the leaderboard shows up at the end of each round.

## Features

- Question packs in plain JSON
- Configurable timer and point values
- End-of-round leaderboard

Write your own packs or start with the sample one that ships with the widget.
